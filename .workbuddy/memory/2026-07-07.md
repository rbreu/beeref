## 编写项目结构文档 `AGENT_GUIDE.md`

- 关键结论：
  - BeeRef = Python + PyQt6 的参考图查看器；MVC + 命令模式；`.bee` 是 SQLite（sqlar 存图）。
  - 改动场景必须经 `commands.py` 的 QUndoCommand 入 `undo_stack`；`save_id` 区分用户对象与 UI 辅助对象。
  - 加菜单项需三处联动：actions.py / view.py on_action_* / menu_structure.py。
  - 耗时操作走 ThreadedIO 后台线程 + 进度信号。

## 性能分析报告
- 审计了全部核心模块，识别出 8 个高/中影响性能问题。
- 详见对话中完整分析报告。主要发现：
  - P0: 保存时逐条 commit + 每次 VACUUM → 保存极慢
  - P0: sample_color_at 每次鼠标移动 toImage() → 取色卡顿
  - P1: itemsBoundingRect 无缓存 → 缩放时重复计算
  - P1: 缩放时 recalc_scene_rect 无防抖
  - P0: 图像无降采样 → 大量参考图时内存爆炸
